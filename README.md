# MacPurge releases

Installers for [MacPurge](https://macpurge.axiomstudio.io), a disk space
analyser and cleanup tool for macOS (Apple Silicon and Intel, macOS 13 or later).

Download the latest version from the
[Releases](https://github.com/dannypenrose/macpurge-releases/releases/latest) page.
MacPurge updates itself from here once installed.

This repository holds release files only; the source is private.

An axiomstudio product. Built by Axiom Studio.
